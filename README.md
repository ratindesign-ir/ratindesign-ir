# سامانه مدیریت اعضا و بدهی‌ها

این پروژه یک اپلیکیشن Django برای مدیریت عضویت، بدهی سالانه، بدهی‌های انتخاب‌شده برای هر عضو و پرداخت‌ها است.

## قابلیت‌ها

- ورود اعضا با کد ملی به‌عنوان نام کاربری
- رمز اولیه برابر با شماره شناسنامه
- الزام تغییر رمز در اولین ورود
- تعریف تعرفه ثابت برای هر سال در ادمین
- انتخاب چند سال برای بدهی هر عضو و محاسبه خودکار مجموع تعرفه‌ها
- ثبت پرداخت‌های هر عضو به‌صورت جداگانه
- نمایش بدهی کل، پرداختی‌ها و بدهی باقیمانده در پروفایل عضو و پروفایل عمومی

## راه‌اندازی

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

پس از اجرا:

- پنل ادمین: `http://127.0.0.1:8000/admin/`
- عضویت: `http://127.0.0.1:8000/signup/`
- ورود: `http://127.0.0.1:8000/login/`

## روند کاری ادمین

1. در بخش «تعرفه‌های سالانه» برای هر سال یک مبلغ ثبت کنید.
2. در بخش «بدهی‌های اعضا» عضو را انتخاب کنید.
3. چند سال را در فیلد «سال‌های بدهی» انتخاب کنید.
4. پس از ذخیره، فیلد «مبلغ محاسبه‌شده» برابر مجموع تعرفه سال‌های انتخابی می‌شود.
5. پرداخت‌ها را در بخش «پرداخت‌ها» به‌صورت جداگانه برای هر عضو ثبت کنید.
